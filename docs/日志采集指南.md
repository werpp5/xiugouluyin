# 日志采集指南

> 采集器 App 开发中，本文先说明采集目标和隐私原则。当前可用 C1 主 App 的"运行日志"功能做初步采集。

## 为什么需要采集日志

搜狗录音笔型号很多，协议大同小异但细节不同。要把一个新型号加入支持列表，维护者必须看到**真实的命令与回包**，否则无法制作设备档案。

采集器是一个**独立的小 App**（不在主 App 里），只有四件事：扫描 → 连接 → 自动记录 hex 日志 → 导出分享。没有转写、没有模型、极简页面。

## 采集步骤（采集器发布后）

1. 安装采集器 App，授予蓝牙权限。
2. 扫描并连接你的录音笔。
3. App 自动记录连接过程中的所有命令与回包。
4. 按屏幕提示，依次点击探测按钮：
   - 读设备信息 / SN
   - 读电量
   - 读会话列表
   - 读文件列表
   - 查询空间
   - 隐蔽开关查询
   - 开始录音 2 秒后停止（可选，用于采集音频帧）
5. 点"导出日志"，把生成的文件发到 Issues 或维护者指定渠道。

## 采集内容

| 类别 | 内容 |
|---|---|
| 设备信息 | 设备名、SN、GATT 服务与特征 UUID 清单 |
| 命令日志 | 每条发出的命令 hex + 时间戳 |
| 回包日志 | 每个通知/指示的 hex + 时间戳 |
| 音频帧 | `B001` 通道原始帧（抽头样本 + 按间隔采样，避免日志爆炸） |

## 隐私说明（重要）

- **采集器本身不联网**。日志存在手机本地，由你手动导出、手动发送。
- 日志里可能包含 **SN、MAC 地址等标识符**。导出界面会提供勾选框，可对这些字段打码后再导出。
- 日志不含录音音频内容（只记录协议帧的结构），但音频帧样本可能含可还原的声音片段——介意的话导出时取消勾选"包含音频样本"。
- 你完全控制发不发、发哪些。不导出，日志只留在你手机里。

## 临时替代方案

当前主 App 设置页有"运行日志"开关，打开后可看到连接与协议交互的文字日志。如果你在 C1 之外的型号上试装，欢迎把这些日志连同设备型号一起发到 Issues，作为初步线索。
