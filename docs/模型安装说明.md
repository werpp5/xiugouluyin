# 模型安装说明

本地转写依赖 SenseVoice-Small int8 模型（约 226 MB）。模型不打包在 APK 里，需要单独安装一次。

## 方式一：App 内下载（推荐）

1. 打开 App → 设置 → 转写模型。
2. 点 **「下载模型（约 226MB，下载后自动安装）」**。
3. 进度条走完，App 自动解压、校验并安装，提示"模型已就绪"。
4. 回到录音列表，点任意录音即可转写。

下载的是 GitHub Releases 上的 `sensevoice-int8-v1.zip`（压缩包约 152 MB，解压后 226 MB）。请确保：

- 手机联网（建议 Wi-Fi）。
- 留出至少 **500 MB** 可用空间（压缩包 + 解压后的模型）。
- 下载完成后压缩包会自动清理，不长期占用空间。

如果下载失败（网络不通、Releases 不可达），不会反复重试，可改用方式二。

## 方式二：从本机导入（下载失败时用）

1. 在电脑或其他设备上下载 `sensevoice-int8-v1.zip`，传到手机。
2. App → 设置 → 转写模型 → **「从本机导入模型包」**。
3. 选中 zip 文件，App 自动读取并安装。
4. 也支持直接选裸 `model.int8.onnx` 文件（如果你有未打包的模型）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 点转写提示"本地模型未安装" | 还没装模型，按上面两种方式之一安装。 |
| 下载一直停在 0% | 检查网络；在国内可考虑用方式二（手动下载后导入）。 |
| 提示"模型文件不完整" | 下载中断了，删除缓存重新下载，或换方式二。 |
| 装完还是不能用 | 确认提示"已就绪"；若显示"已安装"但没有"已就绪"，重启 App 再试。 |
| 会不会每次更新 App 都要重下模型 | 不会。模型存在 App 私有目录，更新 APK 不会清除。卸载 App 才会删除。 |

## 校验信息

| 项 | 值 |
|---|---|
| 模型版本 | `int8-v1` |
| 模型文件 | `model.int8.onnx` |
| 原始大小 | 226 MB |
| 压缩包 | `sensevoice-int8-v1.zip`（约 152 MB） |
| 模型 MD5 | `7cf0eec0a8faa75ec72e774ed03597e2` |

安装时 App 会检查文件大小（≥200 MB）并校验结构，损坏的文件不会被安装。
