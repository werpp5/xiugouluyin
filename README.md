# 修狗录音助手 · 搜狗录音笔复活工具

> 让停服的搜狗录音笔重新可用。蓝牙下载 → 本地 CELT 解码 → 本地 SenseVoice 转写，默认全程离线，音频不出手机。

搜狗录音笔业务已经停止服务，官方 App 无法再完成设备绑定和转写。这个项目的目标是把存量录音笔从"变砖"状态救回来，并逐步支持更多型号。

## 当前状态

| 项目 | 情况 |
|---|---|
| 已验证型号 | 搜狗 C1 / C18D（真机跑通全流程） |
| 核心功能 | 蓝牙连接、电量、录音列表、下载、CELT 解码、本地转写、现场录音（普通/采访/演讲）、暂停续录、隐蔽录音、空间查询 |
| APK 体积 | 约 18 MB（模型外置，不再打包） |
| 模型 | SenseVoice-Small int8（约 226 MB），首次使用时从 Releases 下载并自动安装 |
| 架构 | 仅 `armeabi-v7a`（32 位） |
| 联网 | 默认完全离线；仅"下载模型"和"检查更新"两个动作按需联网，均为一次性匿名请求 |

## 快速开始

1. 到 [Releases](../../releases) 下载最新版 APK，安装到安卓手机（允许"未知来源"）。
2. 打开 App，授予蓝牙 / 附近设备 / 定位权限。
3. 录音笔开机、确认没连其他手机，点顶部"未连接"扫描并连接。
4. 点"设置 → 转写模型 → 下载模型"，下载约 226 MB 的模型包，完成后自动安装。
5. 回到录音列表，点任意录音即可下载并转写；或点"+"现场录音，边录边出字。

如果下载模型失败（网络不通），可以手动把模型包传到手机，用"从本机导入模型包"完成安装。详见 [docs/模型安装说明.md](docs/模型安装说明.md)。

## 隐私边界（重要）

- **默认离线**：蓝牙下载、解码、转写全部在本机完成，不上传任何音频或文字。
- **仅两处联网**：下载转写模型（从 GitHub Releases）、检查更新（GitHub API）。两者都不带设备标识、账号或音频。
- **云端转写是可选功能**：如果你在设置里填写了第三方 OpenAI 兼容服务商，转写会走云端——**这时音频会离开本机，数据处理由该服务商负责，本项目不承担相关隐私风险**。默认不启用。
- **无账号、无埋点、无遥测**。

## 为什么模型不打包进 APK

早期版本把 226 MB 模型塞进 assets，APK 高达 174 MB，且每次更新模型都要重装整个 App。现在模型独立成 Releases 资产：

- APK 只有 18 MB，安装快、更新轻。
- 模型带版本号（`int8-v1`），升级模型不用动 App。
- 用户按需下载，不装的模型不占空间。

代价是首次使用需要联网下载一次模型（约 152 MB 压缩包）。这是本项目唯一必须的联网动作。

## 支持更多型号

目前只在 C1/C18D 上验证过。协议相关的常量（UUID、命令号、回包步长、CELT 参数）已收敛到 `assets/profiles/c1.json`，由 `DeviceProfile` 加载。

理论上同厂同代产品共用这套协议，但音频编码和录音命令差异很大，**换型号能否用必须实测**。项目计划引入采集模式，让有设备的用户导出协议日志，再由维护者逆向成新的设备档案。

- [设备支持表](docs/设备支持表.md)
- [新型号适配流程](docs/新型号适配流程.md)
- [日志采集指南](docs/日志采集指南.md)（采集器 App 开发中）

## 已知限制

- **32 位 only**：CELT 解码库只有 `armeabi-v7a` 版本，少数移除 32 位支持的纯 64 位旗舰可能装不上。已在路线图中。
- **模型幻觉**：SenseVoice 在纯静音上偶尔输出语气词，已做静音门控 + 文本过滤缓解，但无法完全根除。
- **翻译**：SenseVoice 只做识别，实时翻译需要云端大模型接口，列为未来功能。

## 开发

用 Android Studio 打开本目录（含 `settings.gradle` / `build.gradle` / `gradlew`），或命令行：

```bash
./gradlew assembleDebug
```

源码结构：

```
app/src/main/java/com/c1local/app/
├── MainActivity.java     主界面与交互
├── DeviceProfile.java    设备档案（读 assets/profiles/*.json）
├── Proto.java            协议命令构造与解析
├── PenLink.java          BLE 连接管理
├── Downloader.java       录音下载与解码
├── Recorder.java         现场录音
├── WavFile.java          CELT → WAV
├── Transcriber.java      本地 SenseVoice 转写
└── CloudTranscriber.java 云端转写（可选）
```
